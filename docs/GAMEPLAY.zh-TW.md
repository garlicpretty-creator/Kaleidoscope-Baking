# 森羅物語：烘焙 — 玩法說明

遊戲內也可以在**廚房食譜書 →「烘焙」分頁**查到每個物品的配方與站點用法。

## 站點

| 站點 | 怎麼用 |
|------|--------|
| **烤箱**（3×3×3） | 需要 3×3×3 空地，正面朝向放置的玩家。手持燃料（煤、木炭、原木、烈焰棒、岩漿桶…）點擊加柴；手持麵團 / 麵糊放入（4 格，模具自動從背包拿）。時間到「叮」一聲時空手取出；放太久會烤焦。潛行空手可取出未完成的東西；潛行手持一疊麵團 / 麵糊會一次放滿所有空格。烤箱**正下方**（底層中央那格的下面）放箱子、木桶或漏斗時，烤好的東西（連模具）一烤好就自動落進去，不會烤焦；容器放不下時就留在烤箱裡。敲任一格會拆掉整座並掉落內容物。 |
| **攪拌盆** | 放入最多 9 樣材料，用打蛋器攪拌（奶泡類用奶泡器）。空手取回最後一樣，潛行空手全部取回。**潛行**手持材料：一次放入整份配方（盆裡已有的材料加上背包裡的，第一個湊得齊的配方；想做特定配方就先放一樣它獨有的材料）；材料夠的話最多一次 4 份，成品也 ×4。**潛行**拿打蛋器：剩下的每一下自動打完。 |
| **發酵籃** | 放入麵團（最多 16 個）等它發酵；旁邊有火、點燃的爐子或烤箱會快一倍，冰雪會慢一半。 |
| **裱花台** | 先放蛋糕胚或塔殼，再依序放上配料；配方完成時空手點擊取得成品。 |
| **咖啡機** | **需要紅石訊號**（拉桿、紅石塊…），訊號越強越快。用水桶加水；放入咖啡粉，可先放奶泡、奶蓋、巧克力醬、焦糖、肉桂粉來做拿鐵等。完成後空手取出（背包要有馬克杯）。水箱滿時再用水桶 = 加熱水做美式。 |
| **手沖架** | 放咖啡粉 → 手持水桶點擊，立刻沖好（需要馬克杯）。不需紅石。 |
| **雪克杯** | 放入材料，空手搖 5 下；最後一下會跳出選單選**甜度**（全糖～無糖、甜菊）與**冰塊**（正常冰～去冰、溫、熱）。需要外帶杯。潛行空手倒出材料。 |
| **香草盆栽** | 種香草插枝或草莓，室內也能種，速度是地面的一半。 |

## 主要製作流程

- **麵包**：麵粉 ×2 + 水 + 酵母 → 吐司麵團 → 發酵籃 → 烤箱（吐司模）→ 吐司 → 廚房砧板切片
- **蛋糕**：麵粉 + 蛋 + 糖 + 牛奶 → 蛋糕麵糊 → 烤箱（蛋糕模）→ 海綿蛋糕 → 裱花台（鮮奶油、草莓）→ 草莓鮮奶油蛋糕（再加蠟燭 = 生日蛋糕）
- **派**：派皮麵團 → 廚房砧板 + 擀麵棍 → 派皮 → 攪拌盆加餡料 → 烤箱（派盤）
- **咖啡**：咖啡樹採咖啡果 → 砧板 → 生豆 → 烤箱（烤盤）烘焙：早取＝淺焙、中間＝中焙、晚取＝深焙 → 廚房石磨 → 咖啡粉
- **珍珠奶茶**：樹薯 → 石磨 → 樹薯粉 + 黑糖 + 水 → 生粉圓 → 廚房湯鍋 → 珍珠；茶葉 → 湯鍋 → 紅茶湯底；雪克杯：紅茶湯底 + 牛奶 + 珍珠

## 飲食效果

- **咖啡因**：咖啡給急迫與速度。咖啡因值 3–4 心悸（反胃，咖啡正面效果失效）、5 以上嚴重心悸（反胃、虛弱、緩慢）。每分鐘自然 −1；牛奶、熱可可、廚房的茶、薰衣草可以 −1。
- **下午茶加成**：喝飲料與吃甜點相隔 30 秒內，額外飽食度＋吸收效果。
- **香料**：迷迭香佛卡夏 / 鹹派 → 抵抗；肉桂捲 / 肉桂拿鐵 → 回復；薰衣草餅乾 → 解除反胃；魚肉鹹派 → 水下呼吸…
- **手搖飲**：甜度越高飽和度越高；冰飲給速度，熱飲給回復。

## 看得到的製作過程

不靠文字提示，站點上看得到內容與動作：攪拌盆裡的麵糊會隨材料升高並變色、打蛋時打蛋器繞圈；發酵籃的麵團慢慢膨脹；裱花台上的蛋糕一層層疊高並在轉台上轉；咖啡機萃取時咖啡從沖煮頭流下、完成後杯裡有咖啡油脂；手沖架沖水後咖啡滴落、玻璃壺水位上升；雪克杯每搖一次就晃動。烤箱放入或取出東西時爐門會打開再關上，烘烤中門上的小窗發光，烤好時冒出蒸氣，火口的火會跳動。材料加進站點時內容物會彈一下；吃或切蛋糕、派時會噴出碎屑。放在地上的咖啡會冒蒸氣。

畫面上不會出現任何文字。放不進去、拿錯工具、沒帶杯子或模具、吃飽了、烤箱放不下時，會發出一聲低音並冒一小團煙，手上的東西不會被拿走。咖啡因過量時聽得到自己的心跳（越嚴重越快），緩和下來時有一聲輕響；下午茶加成有一聲提示音和愛心。

## 擺放

- **整顆蛋糕 / 派**：放在地上分 4 片吃，用刀可切下一片；切面看得到內層，蛋糕上的草莓、蠟燭等裝飾會跟著那一片一起被吃掉。
- **馬克杯咖啡**（濃縮、美式、拿鐵、卡布奇諾、摩卡、焦糖瑪奇朵、肉桂拿鐵、三種手沖）：對著地面使用就放下一杯；拿著同一種咖啡再點一次就多放一杯，一格最多 4 杯，和森羅廚房的茶杯一樣。空手點一下拿回一杯，打掉會把每一杯都掉回來。
  手搖杯（珍珠奶茶等）和熱可可會記住甜度與冰塊，所以不能放下。

## 植物

在對應生態域野外可找到；破壞草叢也有機率掉落插枝 / 種子。

| 植物 | 生態域 | 採收 |
|------|--------|------|
| 迷迭香、百里香、薰衣草、薄荷（會蔓延） | 平原、森林、繁花森林、河岸、沼澤 | 成熟後右鍵採收，植株保留 |
| 香草蘭（種在叢林原木或泥土上） | 叢林、竹林 | 右鍵採收青香草莢 → 竹篩曬乾 |
| 咖啡樹、草莓、藍莓、覆盆子 | 叢林 / 平原 / 針葉林 / 森林 | 右鍵採收 |
| 芝麻、甜菊、樹薯（耕地） | 熱帶草原、沙漠、叢林 | 成熟後破壞收成 |
| 肉桂樹 | 叢林 | 用刀或斧頭右鍵原木剝樹皮，會慢慢長回來 |
| 檸檬樹 | 熱帶草原、海灘 | 樹葉結果後右鍵採收 |
| 鳳梨（冠芽種在耕地） | 熱帶草原、海灘 | 成熟後破壞收成；裝了豐收時以豐收為主 |

## 系列互通

裝了草本 / 豐收 / 樂牧時，重疊的植物與材料以該模組為主（香草→草本、水果→豐收、製造材料→樂牧）。配方兩種版本都能用；世界中的烘焙植物會自動換成主導模組的版本（可在食譜書「烘焙設定」關閉）。

兩邊都有的東西以這兩個模組為準：水果、肉桂與水果製品（草莓、藍莓、檸檬、鳳梨、鳳梨冠芽、草莓 / 藍莓果醬、藍莓派、鳳梨酥、肉桂樹皮）→ 豐收；乳製品與蛋製品（奶油、鮮奶油、卡士達、蛋塔、蛋塔生胚）→ 樂牧。烘焙的站點兩種都收。手持其中一種對**發酵籃**使用，整疊會一對一換成另一個模組的版本（再用一次換回來）；只在那個模組有裝時才換。

## 1.1 新增

### 擺放與展示

| 方塊 | 怎麼用 |
|------|--------|
| **熱咖啡** | 手持拿鐵、美式等熱咖啡對桌面使用即可放下（烘焙的馬克杯），同一種飲料一格最多疊 4 杯；空手拿回 |
| **手搖飲** | **潛行**手持手搖飲對方塊頂面使用即可放下，最多 4 杯；拿回時甜度與冰塊不變 |
| **蛋糕架** | 放一個整顆蛋糕或派，一樣一片一片吃；潛行空手拿回完整甜點 |
| **三層點心架** | 放 3 個小點心；從架上吃，下午茶加成時間放寬到 60 秒 |
| **麵包展示櫃 / 甜點櫥窗** | 9 格收納，前 3 格顯示在櫃子裡；拆掉會掉出全部內容 |

蛋糕架、點心架、展示櫃會直接顯示放在上面的東西；手搖杯擺放時看得到杯子。（站點本身的動畫見上方各站點說明。）

### 新點心

- **千層酥皮**：派皮麵團 + 奶油 ×2 → 千層麵團 → 廚房砧板用擀麵棍擀 3 次 → 千層酥皮
  - 烤酥皮 → 裱花台：烤酥皮 + 卡士達 + 烤酥皮 + 糖 → **拿破崙派**
  - 千層酥皮 + 糖 → **蝴蝶酥**；+ 卡士達 → **葡式蛋塔**；+ 任一湯品（含廚房的湯）→ **酥皮濃湯**
- **瑪德蓮**：麵粉、蛋、奶油、糖、檸檬 → 瑪德蓮模
- **蛋黃酥**：雞蛋放在廚房竹篩淋雨醃製 → 鹹蛋 → 砧板 → 鹹蛋黃；千層酥皮 + 鹹蛋黃 + 芝麻醬 → 烤
- **鳳梨酥**（鳳梨野生於熱帶草原、海灘，冠芽種在耕地；裝了豐收時以豐收的鳳梨為主）：鳳梨 ×2 + 糖 + 玻璃瓶 → 攪拌盆 → 鳳梨醬 → 麵粉、奶油、蛋、鳳梨醬 → 鳳梨酥模
- **馬拉糕**：廚房蒸籠
- **糖霜餅乾**：餅乾麵團 + 餅乾切模（砧板）→ 造型餅乾；糖 ×2 + 蛋 → 白色糖霜，加染料變 6 色；攪拌盆放 4 片造型餅乾 + 糖霜，用**擠花袋**點 3 下
- **奶油濃湯**：廚房湯鍋倒入牛奶，再加蔬菜和奶油
- **炸魚排**：廚房炒鍋：魚 + 麵包屑 + 蛋

### 副產品

| 副產品 | 來源 | 用途 |
|--------|------|------|
| 咖啡渣 | 咖啡機、手沖架每次沖煮 | 當作溫和的肥料：對烘焙植物用一次 +1 階段 |
| 果渣 | 檸檬水、檸檬茶、草莓牛奶 | 堆肥；裝了樂牧時可以放進飼槽，豬和兔子會吃 |
| 麵包屑 | 法棍、麵包放砧板 | 炸魚排；裝了漁歌時可以當魚餌 |

### 奶油罐

空罐子 + 奶油 ×4 → 奶油罐（8 份）。拿著奶油罐，廚房炒鍋可以用奶油代替油。
